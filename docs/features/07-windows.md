# 窗口：Frag / Window / WindowManager

> 入口：mod-tools 菜单 → 各工具窗口；**WindowManager** 单独一个内容

## Frag

Frag 是停靠在屏幕边缘的小窗：

- 双击 Frag 的蓝色部分可最小化/恢复；
- 最小化后点击蓝色部分，行为像一个悬浮球。

## Window

所有 mod-tools 窗口共用一套行为：

| 操作 | 快捷键/方式 |
|:--|:--|
| 切换窗口 | `Ctrl` + `Tab` |
| 关闭当前窗口 | `Shift` + `F4` |
| 移动/缩放 | 右键单击关闭按钮，拖动/滚轮调整 |
| 置顶 | 标题栏的图钉按钮 |
| 最大化 | 标题栏的放大按钮 |
| 最小化 | 标题栏的折叠按钮 |

窗口标题会显示当前焦点；多个窗口重叠时，标题颜色会区分前台窗口。

## WindowManager

WindowManager 列出当前所有 mod-tools 窗口，用来找回被拖到屏幕外或压在别的窗口下面的窗口：

- 双击列表项：强制把该窗口拉回可见区域并置顶；
- 列表会定期重建，显示窗口的当前状态；
- WindowManager 自身强制置顶，避免它自己也被盖住。

> 窗口位置/大小会保存；如果某次改分辨率后窗口跑出屏幕，用 WindowManager 双击找回即可。
